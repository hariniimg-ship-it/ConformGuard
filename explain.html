ConformGuard: What it does

ConformGuard is a release safety checker for digital identity systems. Before deployment, it gathers the results of your security and standards tests and gives one decision: Release approved or Release blocked.

The two things it verifies

CheckPlain meaningExamples checked
CertifyIs the login/identity issuer working securely?PKCE protection, safe redirect URLs, signing keys (JWKS)
VerifyIs the credential verifier accepting only trustworthy digital credentials?Credential signature, expiry date, revocation/status list
CombinedIs the complete identity release safe?Runs both checks plus the quality gate

These buttons simulate the test results that the Python backend receives from OpenID and Inji systems.

Decision and explanation

Choose a test above. A passing result means it is safe to release; a blocked result means a security check regressed.

How the real project works

  1. OpenID and Inji test suites produce JSON results.
  2. The included Python CLI normalizes those results.
  3. ConformGuard compares them with the previous approved report.
  4. If a test fails, score is below 95%, or a new regression appears, CI blocks the deployment.
